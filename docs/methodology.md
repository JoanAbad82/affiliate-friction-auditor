# Methodology

Goal: detect affiliate monetization friction in commercial hub/listing pages.

Workflow:

1. Phase 0.7 renders hubs and destination posts.
2. Phase 0.8 builds the opportunity matrix.
3. Phase 0.9 converts the matrix into a product/service proposal.

Classification principles:

- UTM parameters alone are not treated as affiliate signals.
- Internal category pages are not treated as cloaking by default.
- Reliable cloaking patterns include /go/, /out/, /ir/, /comprar/, /redirect/, /recommends/, /link/ and /cupon/.
- ROI is modelled as scenarios, not guaranteed revenue.
